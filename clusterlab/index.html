Le companion du livreThe book’s companion

De l’algorithme à la production — Frédéric Ros

Le livre suit une application, ClusterLab, du premier script jusqu’à la production. Le companion permet de refaire ce chemin soi-même, sur sa machine.

The book follows an application, ClusterLab, from its first script to production. The companion lets you walk the same path yourself, on your own machine. The companion is in French.

Ce qu’il contientWhat it contains

  • le code de chaque chapitre, prêt à lancer, et ses tests ;
  • the code for each chapter, ready to run, with its tests;
  • 81 labs, trois par chapitre, et un super-lab qui rejoue toute l’histoire de ClusterLab ;
  • 81 labs, three per chapter, and a final lab that replays ClusterLab’s whole story;
  • le livret « Guides des labs » : étapes guidées, questions et éléments de réponse ;
  • the lab guide booklet: guided steps, questions and suggested answers;
  • les corrigés des exercices, les TP guidés et un carnet de bord d’une page par chapitre.
  • solutions to the exercises, guided practicals and a one-page summary per chapter.

Une partie est en accès libre sur le dépôt public : vous pouvez l’essayer avant d’acheter le livre.

Part of it is freely available in the public repository: you can try it before buying the book.

Comment y accéderHow to get access

L’accès au companion complet est inclus dans le prix du livre, broché ou Kindle. Il n’est pas automatique : il se fait par une invitation à un dépôt GitHub privé.

Access to the full companion is included in the price of the book, paperback or Kindle. It is not automatic: you receive an invitation to a private GitHub repository.

  1. Si vous n’en avez pas, créez un compte gratuit sur github.com.
  2. If you do not have one, create a free account on github.com.
  3. Écrivez à contact@frederic-ros.com en indiquant votre identifiant GitHub, et joignez votre justificatif d’achat : une capture de la commande Amazon où figurent le titre et la date suffit. Masquez le reste (adresse, moyen de paiement).
  4. Write to contact@frederic-ros.com with your GitHub username, and attach your proof of purchase: a screenshot of the Amazon order showing the title and date is enough. Hide everything else (address, payment details).
  5. Vous recevez une invitation de GitHub par e-mail, en général sous quelques jours. Acceptez-la dans la semaine : passé ce délai, elle expire, et il suffit de me réécrire.
  6. You will receive an invitation from GitHub by e-mail, usually within a few days. Accept it within a week: after that it expires, and you can simply write again.

Livre reçu en cadeau, ou pas de justificatif à portée de main ? Écrivez quand même, en le précisant : je trouverai une solution.

Received the book as a gift, or no proof of purchase at hand? Write anyway and say so: I will find a way.

Ce que vous pouvez en faireWhat you may do with it

Le companion est destiné à votre usage personnel : lisez, lancez, modifiez et réutilisez le code dans vos propres projets. Merci de ne pas redistribuer les guides, les corrigés ni le dépôt privé lui-même : c’est ce qui permet de continuer à l’inclure dans le prix du livre.

The companion is for your personal use: read, run, modify and reuse the code in your own projects. Please do not redistribute the guides, the solutions or the private repository itself: that is what keeps it included in the price of the book.

Vos données. Votre identifiant GitHub et votre adresse e-mail servent uniquement à vous envoyer l’invitation et à vous répondre. Le justificatif d’achat est supprimé dès la vérification faite. Vous pouvez demander à tout moment le retrait de votre accès et la suppression de ces informations, à la même adresse.

Your data. Your GitHub username and e-mail address are used only to send you the invitation and to reply to you. The proof of purchase is deleted as soon as it has been checked. You can ask at any time for your access to be removed and this information deleted, at the same address.
